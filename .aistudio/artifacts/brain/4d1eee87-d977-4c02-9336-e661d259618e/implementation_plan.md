# خطة تنفيذ إعادة ترتيب قسم البطل (Hero Section) لشاشات الجوال فقط

## 1. نظرة عامة والهدف التصميمي
يهدف هذا التحديث إلى إعادة هيكلة التسلسل البصري العمودي لقسم البطل (Hero Section) في الصفحة الرئيسية **على شاشات الجوال حصراً** (`أقل من 640px`)، ليحقق انسيابية قراءة طبيعية وتوازناً بصرياً يبدأ بالتعريف الشخصي، ثم الصورة الشخصية في قلب التكوين، تليها الإحصائيات الموثقة، وأخيراً أزرار اتخاذ القرار (CTA) في الأسفل لسهولة الوصول بالإبهام، مع الحفاظ التام على الهوية البصرية البترولية والتركوازية وعدم المساس بتصميم الحاسوب أو الأجهزة اللوحية أو أي قسم آخر في الموقع.

---

## 2. القرارات المعتمدة وتفضيلات تجربة المستخدم
بناءً على المتطلبات وتفضيلاتك المؤكدة:
- **توسيط كامل للمقدمة النصية:** محاذاة الشارات التعريفية، والاسم العربي «رشيد الفلاحي» والإنجليزي «Rasheed Alfalahi»، والوصف التعريفي في المنتصف تماماً فوق صورة المصمم المتمركزة.
- **تكديس أزرار الإجراءات عمودياً بعرض كامل:** عرض زري «استكشف صالة المشاريع» و«ابدأ مشروعك معنا» مكدسين عمودياً (`100% width`) أسفل بطاقات الإحصائيات على جميع مقاسات الجوال لضمان سهولة اللمس والوضوح.
- **إعادة الترتيب عبر CSS فقط دون تكرار عناصر DOM:** استخدام خاصية `display: contents` على حاويتي النصوص والصورة داخل شبكة الجوال فقط، مما يسمح بترتيب العناصر الستة مباشرة عبر خاصية `order` في استعلامات الوسائط (`Media Queries`) دون إنشاء أقسام مكررة أو المساس بشجرة العناصر الأصلية.

|                         ↕                             |
|              +-----------------------+                |
|              |                       |                |

|              |                       |                |

## 4. تفاصيل التنفيذ التقني وضبط المسافات

### أ. آلية إعادة الترتيب النظيف (`< 640px`)
- تحويل حاوية الشبكة الرئيسية في قسم البطل على الجوال إلى عمود مرن واحد (`display: flex; flex-direction: column; align-items: center`).
- تطبيق `display: contents` على كلٍّ من عمود النصوص وعمود العناصر البصرية داخل نطاق الجوال فقط، لتصبح العناصر الفرعية أبناءً مباشرين للحاوية المرنة بالترتيب التالي:
  1. **الشارات التعريفية (`order: 1`):** في الأعلى مع تباعد سفلي متوازن (`1rem`).
  2. **الاسم العربي والإنجليزي (`order: 2`):** أسفل الشارات مباشرة مع الحفاظ على التدرج اللوني وحجم الخط المتجاوب.
  3. **الوصف التعريفي (`order: 3`):** أسفل الاسم مباشرة مع مسافة سفلية مدروسة (`1.5rem`) تفصله عن الصورة.
  4. **إطار صورة المصمم (`order: 4`):** أسفل الوصف مباشرة، متمركز أفقياً بعرض متوازن (`clamp(210px, 64vw, 275px)`) مع الحفاظ على النسبة الأصلية (`4:5`) والوهج الخلفي دون أي قص أو تداخل.
  5. **بطاقتا الإحصائيات (`order: 5`):** أسفل الصورة مباشرة في شبكة من عمودين متجاورين (`grid-template-columns: repeat(2, minmax(0, 1fr))`) بنفس العرض الأقصى للصورة والأزرار (`360px`) لخلق عمود بصري متناغم، مع السماح بالتفافها تلقائياً على الشاشات فائقة الصغر.
  6. **أزرار الإجراءات (`order: 6`):** في نهاية القسم أسفل بطاقات الإحصائيات، مكدسة عمودياً بعرض كامل (`grid-template-columns: 1fr`) مع مسافة مريحة بين الزرين.

### ب. معالجة الهوامش ومنع التداخل
- **أعلى القسم (تحت الهيدر):** ضبط الهامش الداخلي العلوي (`padding-top: clamp(6.5rem, 18vw, 7.5rem)`) لضمان عدم اقتراب الشارات من شريط التنقل الثابت في جميع الهواتف.
- **أسفل القسم (حماية زر واتساب العائم):** ضبط الهامش الداخلي السفلي (`padding-bottom: clamp(5.25rem, 15vw, 6.25rem)`) مع السماح للقسم بالتمدد العمودي الحر (`min-height: auto`) بحيث لا يغطي زر واتساب العائم أزرار الإجراءات أو الإحصائيات.
- **عزل التعديلات بالكامل:** حصر جميع القواعد داخل استعلامات شاشات الجوال فقط دون أي تغيير في تصميم الأجهزة اللوحية أو الحواسيب المكتبية أو بقية أقسام الموقع.
